# Dibyansu Behera — SOC Analyst Portfolio

A responsive, dark-green portfolio showcasing cybersecurity training, SOC-focused skills, experience, projects, education, and certifications.

## Live site

After GitHub Pages is enabled and the first deployment succeeds, the site will be available at:

<https://dibyanshubehera.github.io/portfolio/>

## Run locally

This is a static website with no build step or package dependencies. Open `index.html` in a browser, or serve this directory with any static file server.

## Deploy with GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the repository root to GitHub Pages whenever changes are pushed to `main`.

1. Create a **public** GitHub repository named `portfolio` and push these files to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **GitHub Actions** as the source.
4. Open the **Actions** tab and wait for the Pages deployment workflow to finish.

The workflow can also be started manually from the Actions tab.
